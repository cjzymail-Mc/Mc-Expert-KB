## 你要做的（就这一件事，别扩展、别重开任务）

1. 从**本对话上下文**认出两样东西：
   - **纠正原文** = 用户在这条 `/pin` **之前那一条**真实纠正（不是 /pin 本身；如果 /pin 前一条是我在回应、再往前才是纠正，就取那条纠正）。
   - **被纠正的 AI 动作** = 我当时说/做的、被这条纠正指向的那段（取要点即可，几百字内）。
2. 跑写入器（**绝对路径**，因为本命令已铺开到 3 账号、可能从任意 repo 调用；路径含中文/空格务必整体引号）：
   ```
   python "D:/Downloads/Mc Claude Code Workshop/Mc-emoji/[feature-05-loop-self-improvement]/历史扫描/pin_capture.py" --corr "<纠正原文>" --ai "<被纠正的AI动作要点>" --note "$ARGUMENTS"
   ```
   脚本用自身所在目录算 `out/`，所以不管你在哪个 repo `/pin`，候选都汇到 feature-05 的 `out/pinned-candidates.jsonl` 这一个中央 sink。
   - `$ARGUMENTS` = 用户在 `/pin` 后可能附的一句备注（没有就传空）。
   - 若这条纠正后用户已给了「错因/想要啥」的补充，可加 `--followup "<那句>"`。
3. 只回一行确认（脚本会打印 `✅ 已 pin…`，把它转述给用户即可），**不要**复述纠正内容、不要顺势去"修那个错"（除非用户另外要求）。
