# temp 接力模式

1. 定位当前 repo 根目录的 `temp.md`。文件不存在则停止并报告路径，不新建、不猜其他位置。
2. 在同一次工具调用中连续完成：读取全文 → 立即清空同一个文件 → 验证文件长度严格为 `0`。清空或验空失败时立即停止；禁止分析、执行或回复已读内容。
3. 仅在验空成功后，根据刚才读取的信息和用户为本 session 指定的角色继续工作。若读到的内容为空，报告「当前没有待接力内容」并停止。
4. 完成本阶段后，先确认 `temp.md` 仍为空；若已出现新内容，停止并报告冲突，禁止覆盖。
5. 将简洁交接写入 `temp.md`，至少包含：本 session 角色、已完成事项、关键结果或产物路径、下一棒需要做什么。此时结束本轮，等待用户在另一个 session 手工触发 `/temp-command`。

## 边界

- 本 skill 是最便宜的手工单棒接力，不自动轮询、不自动唤醒另一个 session。
- 同一时刻只允许一个 session 触发；不要在两个窗口同时运行。
- 不因进入本模式扩大文件写入、删除、联网或对外交付权限。
