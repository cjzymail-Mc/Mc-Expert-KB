# 工程独立陪审案例

<a id="m01"></a>

## M01 交接执行与独立验收分开取证

历史任务要求分别检查协作过程和实际产物。同类审查先找被审版本，再定位与本次决定相符的证据。过去的意见和历史案例仅供查找风险点，最终结论须由本轮既有合同规定的证据支持。

另一次交付中，用户指出技能要求独立复核业务映射。助手承认抽取、编译和结构校验均通过后，直接交给用户审核，遗漏了约定的独立源材料复核。该回复提出补做步骤，尚未给出补审结论。复核范围、执行者和证据来源分别留痕，制作方自报与人工看稿不能补足遗漏的独立证据。

历史依据 · 8 月协作验收记录、M01-a。

<a id="m02"></a>

## M02 只复核变化和依赖它的结论

当用户指出已有独立验收，先核对已审对象、版本和范围。如果本次修改影响旧证据或其依赖，要重新验证受影响部分。是否可以沿用已有结果，按现行评审合同判断。

一次非交互工程复核中，委托材料记录主施工者核对了辅助基线的摘要值，发现“旧版”实际装入当前构建器。助手随后报告，按修复前快照重建后已撤销那条结论；修正仅涉及指定的辅助对照。复用旧结论时，连同测试使用的构建器、校验器或输入来源一起核对。

历史依据 · 8 月独立验收反馈、M02-a。

<a id="m03"></a>

## M03 审核背景随项目继承，当前轮的决定单独绑定

用户要求顾问在评审中带上已探明的项目背景，以便任务中断后继续，又追问这些事实是否对多个轮次都成立。助手报告已将稳定背景与本轮冻结规格分开，并说明对跨轮通用性的再次检查仍待裁决。给新评审者交接时，用稳定事实解释项目，用指定版本、轮次和候选对象限定这次裁决；材料复核和最终成品验收各自保留所见证据。

历史依据 · M03-a、M03-b。
