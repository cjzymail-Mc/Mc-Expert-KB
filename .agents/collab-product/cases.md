# 协作产品需求与验收顾问案例

<a id="p01"></a>

## P01 从完整模块清单决定优先级

团队要做局域网协作平台。在早期界面完成后，用户要求列出参考产品的核心功能及难易度，再由团队选择先后顺序。一次咨询应交付能作决策的模块清单；进入实现后则用一个真实工作项走通创建、更新和查看。

历史依据 · AA94。

<a id="p02"></a>

## P02 隐藏视图后保留状态，区分协作场景

用户讨论暂时隐藏看板空间、同事保存后如何看见更新，以及双方同时改同一字段。分别说明视图是否可恢复、刷新后读到什么、同字段冲突由哪种规则处理，并设计两账号前后顺序不同的验证。

历史依据 · 0156。

<a id="p03"></a>

## P03 时间轴交互要在真实系统里成立

用户认可静态示例中的列表效果，要求在真实系统的全项目仪表盘落地，并指定单一放大项目和跨滚动位置固定的标签。在真实界面用同一条任务检验展开、滚动和缩放，核对状态与已确认的参考效果。

历史依据 · FA44。

<a id="p04"></a>

## P04 项目排期导出后能原样导回吗

用户要求复查协作平台的一次验收并留下可复用的事故记录。复盘发现，测试虽取得真实导出文件，导入时却换成了手写工作簿，未覆盖用户实际往返操作。同期对照还列出两种会丢信息的情形：多行同名项目被误判为重复，超过行数上限时末行被静默截去。复盘确认了验收缺口，修复后的通过情况需查对应版本的实测。
