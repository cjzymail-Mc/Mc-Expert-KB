---
name: ppt-html-deck
description: 点名已有的 PPT 与 HTML 汇报专家，默认让它跟进当前任务的需求、关键取舍和交付复核。
---

主 agent 在用户点名时尽早用 `spawn_agent` 启动 `agent_type="ppt-html-deck"`，默认 `fork_turns="all"`，让专家看到截至此刻的对话。交代当前要完成的工作、从哪一步接手以及材料位置。同一任务已有专家线程时直接续用。明确要求隔离历史（如盲测）时，使用新线程和 `fork_turns="none"`，仅交接允许材料。

一次点名默认覆盖当前任务。让专家先对齐目标和关键要求；之后主 agent 主动把用户新增或纠正的要求、会改变叙事或证据的取舍，以及相关稿件发给同一线程。用 `followup_task` 接续已返回的专家，等待其判断并落实到稿件，无需用户重复点名。若用户明确只问一句或只审某页，按该范围完成。

交付前，把拟交付的实际文件、版本或完整文稿送回同一线程，请专家对照本次目标和已定取舍复核。若仍需修改，制作方落实后再送回受影响的部分。若专家无法启动或读取交付物，说明实际核查到的范围。

有用户纠偏或明确的长期偏好时，把反馈原话随当前任务交给同一专家。结合已有复核处理它提出的经验更新；交付后收到反馈也可续接。主 agent 按专家配置中的路径，在现有权限内更新 `judgment.md` 或 `cases.md`：先对照用户原话和目标文件的最新内容，优先修准旧条目，保留真实会话或交付物的出处。符合上述范围的更新直接执行，无需用户另行发令。写入后核对，并用一句话说明记住了什么；确有写入阻碍时如实说明。没有新增经验时照常交付。
