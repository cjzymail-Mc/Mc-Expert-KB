# Keep Simple

以事实支撑明确结论，让读者直接理解结果、依据和取舍。保留用户指定的体裁、结构与详略；简洁不等于删掉必要解释。

- 分析与汇报优先采用“结论 → 证据 → 实际意义”。回答读者关心的问题，用已有事实、具体数值和性能取舍支撑判断；其他体裁沿用原有表达方式。
- 去掉空泛、反复的推测、退让和说教，如“可能”“未必”“不能一律”“不能作为”“不代表”。按句意改写论点，不做机械禁词或同义词替换。
- 用肯定的事实交代范围，例如“在该样本／工况下，结果为……”。关键条件与结论一起保留，详细方法放图注、脚注或备注，避免免责声明堆叠。
- 保持事实含义与证据强度：区分实测、仿真、品牌披露、专利实例与算例。关联、因果和推广范围分别表述；证据不足时明确已有结果与缺失数据，保留影响判断的必要不确定性。
- 删除制图、整理、自我解释等过程话语和空泛总结。涉及取舍时，直接说明哪项改善、代价是什么、适合什么目标。
- 同步处理标题、答句、正文、表格、图内文字、图注、页脚和备注。交付前核对数字、单位、条件及来源；有版式时检查换行与溢出。

基于现有资料完成表达优化，不为增强语气编造事实、数值、因果或结论，也不擅自扩展成新一轮调研。

示例：将“回能提高不能直接换算为人体收益”改为“同样输入10 J，回能率从80%升至85%，每次加载多返回0.5 J；人体收益通过整鞋跑步测试评价。”数字仅在原资料或明确算例支持时使用。

## 汇报 Deck

适用于 deck、幻灯片及汇报类报告的生成与修改。

- 面向听众，每页聚焦一个问题，按“明确结论 → 关键证据 → 实际意义”组织内容。
- 用具体事实、数值和性能取舍表达论点。去掉反复的推测、退让和说教语气，如“可能”“未必”“不能一律”“不能作为”“不代表”；删除制图、整理和自我解释等过程话语。
- 用具体样本、工况与测试方法交代结论范围。影响理解的关键条件简要保留在正文，详细方法和适用范围放图注或备注。
- 表达坚定，证据准确：区分实测、仿真、品牌披露、专利实例与算例；材料指标与人体收益分别评价。证据缺口客观列为缺失数据或评价项目，不补造确定性。
- 标题、答句、正文、表格、图内文字、图注、页脚和备注采用一致的汇报语气；结论应具体回答问题，避免空泛总结和免责声明堆叠。
- 交付前通读全文，核对结论与数据、来源一致，并检查改写后的换行、遮挡及页面溢出。
