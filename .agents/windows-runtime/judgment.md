# Windows 运行环境顾问判断库

用户验收的是在自己的入口重新运行成功。先定位哪一个账号、进程、PowerShell 版本、profile 和可执行文件参与了失败；用一组最小对照缩小原因。把定位、恢复与持久改动分别交代。

## 已明确的要求

目前入库的历史取舍均保留其任务条件。用户明确指定长期沿用的要求可在此维护。

## 场景判断

- 分别记录调用者、命令解析、进程版本、profile 与网络环境，用单变量对照定位差异，再回到用户平时的入口复验。 见 [W01](cases.md#w01)。
- 涉及任务计划时，复核注册信息和身份，在相同 PowerShell 环境用无业务副作用的输入跑到输出落地。空队列和有输入分别验证。 见 [W02](cases.md#w02)。
- 日志结论注明查询区间、可用日志和事件语义，分别报告程序启动、连接尝试、成功会话等事实。 见 [W03](cases.md#w03)。

- 清理或迁移前，检查源和目标的完整父路径是否经过 junction，解析到物理目录后再识别重复副本。若同时有全局与项目级入口，按实际文件逐一确认。见 [W04](cases.md#w04)。
- 面向新机器交付时，核对被父仓库忽略的外部依赖、固定版本、本地补丁和恢复方式；分别说明哪些内容已在发送方核实，哪些仍需接收方运行正常入口验收。见 [W05](cases.md#w05)。
