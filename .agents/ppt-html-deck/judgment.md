# PPT 与 HTML 汇报判断

当次任务中用户明确给出的目的、听众、范围、模板约束和验收条件优先。以下判断用于制作方在叙事、证据和改稿中需要做取舍的场合。案例编号可在 [cases.md](cases.md) 回查用户反馈和实际改稿。

## 已明确的要求

- **一页回答一个具体问题。** 先确认要回答哪些问题，再确定图文和页序。需要解释复杂机制或对照多项证据时，可以用连续几页回答同一主问题，每页各自交代一个结论。用户指定的问题顺序优先于预设页数。页数另有硬约束时，先遵守当次约束。见 A01。
- **先写明确的结论，再用事实讲明条件和意义。** 标题、答句和正文加粗各自承担信息。加粗句应短而具体，读完就知道这页发现了什么或意味着什么。反复的推测、退让、说教和制作过程话语都要收掉。有证据范围时，用样本、工况和测法表达；缺的证据写成缺失数据或待评价项。逐页核对正文、图内文字、图注、页脚和备注。见 A03、A05。
- **技术结论和支撑它的研究证据同页出现。** 材料机理、性能对比或前沿进展涉及具体研究时，优先选直接支撑该结论的原图、曲线、显微图、关键截图或原表。正文交代理解它所需的最少条件，图注或备注带出处和其余方法。参考稿只按用户赋予的用途使用。见 A04、A05。
- **各类证据各自回答相应问题。** 对照研究实测、仿真、品牌披露、专利实例和算例的适用范围。材料或中底指标先写在试样和工况范围内，整鞋表现、人体收益、耐久及量产验收分别对照各自的数据。需改写时保留承重数值、工况和来源，再检查换行、重叠与溢出。见 A02–A05。

## 有依据的场景取舍

- **按新叙事重构已有 deck 时，先用指定母稿对齐新提纲。** 给制作方的第一条意见应点明沿用哪一版，并把能回答各段问题的原图、数据和结论对应到新提纲，保留其工况和来源。已有材料足以说明的内容直接重排，只对新叙事里的证据缺口补充材料。见 A08。
- **初稿的选题与用户追问不一致时，先校问题清单。** 对有长期积累的专题，回到最初主线和被反复追问的细节。可以请制作方先列「问题 → 为什么要讲 → 放在哪一段」，用来确认框架，再投入逐页制作。首轮给十个问题是 A01 的交付安排。
- **图的逼真程度关系到结论时，换证据再改视觉。** 像步行与跑步的力时曲线，比较的就是波形。优先选工况可交代的真实记录，保留峰、肩和关键拐点。缺实测时，明确用的是模拟或示意，并把结论收回到该材料可支持的范围。标注可移到图内空白处，用引线指向实际峰值。见 A02。
- **用户认可图的表达方式、指出对象错误时，保留已认可的关系。** 例如结构疏密已经清楚，图却没有跑鞋中底的形状，换成正确对象的剖面、保留内外结构区分。图注交代概念重构与尺度，另用原研究图支撑材料证据。见 A04。
- **综述值得展开时，保留全局页并按研究拆开。** 用户要听懂多项实验的差别时，可让各页回答一个问题，配同页证据、量化结果和条件。拆几页取决于材料与汇报重点。见 A05。

- **体裁先服从使用场合。** 研发成效汇报和现场评审所需的内容骨架可以不同。若哪种场合会改变结论或必备证据，先就本次目的拍板，再删改章节。旧样本的删页清单只作参考。用户认可汇报版后另要自读版时，保留原稿，在阅读版中沿用主线，展开关键分组和可回查的明细。见 A06、[A21](cases.md#a21)。
- **竞品图表以实际做了对照的对象为主体。** 多款合写时，共线关系可凭现有材料说明。只有一款具备可比实测时，以该款承担对照，其他对象按证据范围交代。涉及已定主轴或交付对象的变更，提一个具体问题请用户决定。见 A07。

## 近期改稿中可复用的判断

按当前任务选用下面的判断。具体页数、配色、独立章节或水印密度沿用本轮约定。

- **辨认底稿与模板各管什么。** 用户重新指向资料夹里的 PPT，先打开该文件核对页数、标题和已有图表，再判断补充放在哪页。固定页数时，先合并重复说明，把空间让给可读字号、实图和关键结论。用户要求对齐模板时，对照实际页面的画幅、标题层级、图文位置及配色；模板里的旧轮次数据按本次材料更新，缺测项按约定留空。见 A12、A14–A16。
- **让听众从图中读出结论。** 用对照图回答“差多少”，趋势图回答“怎么变”；把单位、时期、基数或样本及短出处放在图旁。人物配对应型号，注明是本人实物、比赛上脚还是品牌示意；发布、上市与首次亮相分别核实。研究型 HTML 可把明细和长名单折叠，让首屏和章节主图先回答问题。见 A10、A20。
- **用评论概括一个品类，先看不同型号或样本组是否支持同一结论。** 说明选款覆盖哪些用途或设计路线，标出只作参照的型号。图旁区分原始留言条数与筛选、去重后的评价份数，注明渠道和去重单位，切换分组时同步显示分母。扩样时并列原组和新增组。若某一主题集中在少数型号或某类测评，就把结论写到相应范围。讨论溢价时区分价格评价、购买意向和自报实付。见 A13、[A21](cases.md#a21)。
- **读者需要反复辨认多个型号时，图鉴和逐款数据共用对应的实物照。** 在首次讨论前分组列出型号与照片，逐款图表在名称旁复用缩略图。按要比较的部位选视角和构图，再从交付页打开实图，借助结构或标记核对型号、代际，以及用户指定的朝向和入画范围。见 A10、A14、[A22](cases.md#a22)。
- **把证据矛盾保留在结论旁。** 表值与复算不符时列两者、依据和待核项；样品实测、立项目标与量产配置分别标明。能追到人数的反馈写人数和分母，后来口头补充的定性反馈照实表述。比较运动指标时说明工况和指标含义，如触地时间需结合速度解读。缺实测可用标明身份的示意图解释装置或流程。见 A09、A13–A16。
- **按对象追踪修订。** 将用户圈选的部位、图中左右、系列与颜色一一对应，再检查引用同一对象的曲线、图例、表格、正文和讲稿。删 HTML 章节时一并核对目录、跳转及交互入口；保留其他对象正确的单位和配色。见 A12、A14、A20。
- **转成 PPT 时按已审 HTML 验收。** 用户确认哪一版，就用哪一版逐页对照标题位置、图文层级、留白、图片裁切和换行。文字能点选改写，图片能独立移动或替换；图表按本次约定检验能否改值。请制作方在最终文件的副本试改并保存重开。只拿到页面预览时，可判断版式，编辑能力记为待验证。见 A17。
- **用实际交付方式检查可用性。** 对要拷走或双击展示的 HTML，在最终位置按读者打开方式测试，必要时内嵌图片或连同相对路径素材交付。查看实际彩色图、翻页和本次用到的跳转。HTML 转 PDF 时查看导出后的正文、图注和水印密度。见 A10、A14、A18。
- **按场合安排叙事与讲稿。** 多主题分享先找共同问题，讲清上一段为何引出下一段，趋势并列出现时避免写成未经验证的因果。用户要独立补充章，就给配套稿和原稿的插入点，以页码加前后页标题定位。限时讲稿按用户最后指定的 PPT 页序串讲，压缩目录和重复说明，保留支撑核心判断的数字，为翻页、停顿留出时间。见 A11、A12、A19。
- **原始材料的插图也纳入寻证。** 独立图片目录缺图时，查看成效报告、竞品材料等文档中嵌入的图片及邻近图题。逐张匹配试样、工况和要支持的结论。统计内容图时辨认照片、试验图与整页截图的用途。只有外部改稿才出现的图片，按其实际来源处理。见 [A23](cases.md#a23)。

## 接手一轮分歧

先给制作方一句可执行的话。证据足够时直接决定保留和修改的内容。若分歧会改变目标、听众、证据门槛或关键承诺，且现有资料不足，给用户一个具体问题和建议。拿到改稿后回查同一标准，再给通过或仍需修改的判断。未见用户明确确认的旧交付仅作案例参考。
