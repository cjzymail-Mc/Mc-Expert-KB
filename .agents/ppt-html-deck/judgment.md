# PPT 与 HTML 汇报判断

当次任务中用户明确给出的目的、听众、范围、模板约束和验收条件优先。以下判断用于制作方在叙事、证据和改稿中需要做取舍的场合。案例编号可在 [cases.md](cases.md) 查到原话、版本和记录位置。

## 已明确的要求

- **一页回答一个具体问题。** 先确认要回答哪些问题，再确定图文和页序。需要解释复杂机制或对照多项证据时，可以用连续几页回答同一主问题，每页各自交代一个结论。用户指定的问题顺序优先于预设页数。页数另有硬约束时，先遵守当次约束。见 A01。
- **先写明确的结论，再用事实讲明条件和意义。** 标题、答句和正文加粗各自承担信息。加粗句应短而具体，读完就知道这页发现了什么或意味着什么。反复的推测、退让、说教和制作过程话语都要收掉。有证据范围时，用样本、工况和测法表达；缺的证据写成缺失数据或待评价项。逐页核对正文、图内文字、图注、页脚和备注。见 A03、A05。
- **技术结论和支撑它的研究证据同页出现。** 材料机理、性能对比或前沿进展涉及具体研究时，优先选直接支撑该结论的原图、曲线、显微图、关键截图或原表。正文交代理解它所需的最少条件，图注或备注带出处和其余方法。参考稿只按用户赋予的用途使用。见 A04、A05。
- **各类证据各自回答相应问题。** 对照研究实测、仿真、品牌披露、专利实例和算例的适用范围。材料或中底指标先写在试样和工况范围内，整鞋表现、人体收益、耐久及量产验收分别对照各自的数据。需改写时保留承重数值、工况和来源，再检查换行、重叠与溢出。见 A02–A05。

## 有依据的场景取舍

- **按新叙事重构已有 deck 时，先用指定母稿对齐新提纲。** 给制作方的第一条意见应点明沿用哪一版，并把能回答各段问题的原图、数据和结论对应到新提纲，保留其工况和来源。已有材料足以说明的内容直接重排，只对新叙事里的证据缺口补充材料。见 A08。
- **初稿的选题与用户追问不一致时，先校问题清单。** 对有长期积累的专题，回到最初主线和被反复追问的细节。可以请制作方先列「问题 → 为什么要讲 → 放在哪一段」，用来确认框架，再投入逐页制作。首轮给十个问题是 A01 的交付安排。
- **图的逼真程度关系到结论时，换证据再改视觉。** 像步行与跑步的力时曲线，比较的就是波形。优先选工况可交代的真实记录，保留峰、肩和关键拐点。缺实测时，明确用的是模拟或示意，并把结论收回到该材料可支持的范围。标注可移到图内空白处，用引线指向实际峰值。见 A02。
- **用户认可图的表达方式、指出对象错误时，保留已认可的关系。** 例如结构疏密已经清楚，图却没有跑鞋中底的形状，换成正确对象的剖面、保留内外结构区分。图注交代概念重构与尺度，另用原研究图支撑材料证据。见 A04。
- **综述值得展开时，保留全局页并按研究拆开。** 用户要听懂多项实验的差别时，可让各页回答一个问题，配同页证据、量化结果和条件。拆几页取决于材料与汇报重点。见 A05。

- **体裁先服从汇报场合。** 研发成效汇报和现场评审所需的内容骨架可以不同。若哪种场合会改变结论或必备证据，先就本次目的拍板，再删改章节。旧样本的删页清单只作参考。见 A06。
- **竞品图表以实际做了对照的对象为主体。** 多款合写时，共线关系可凭现有材料说明。只有一款具备可比实测时，以该款承担对照，其他对象按证据范围交代。涉及已定主轴或交付对象的变更，提一个具体问题请用户决定。见 A07。

## 接手一轮分歧

先给制作方一句可执行的话。证据足够时直接决定保留和修改的内容。若分歧会改变目标、听众、证据门槛或关键承诺，且现有资料不足，给用户一个具体问题和建议。拿到改稿后回查同一标准，再给通过或仍需修改的判断。未见用户明确确认的旧交付仅作案例参考。
