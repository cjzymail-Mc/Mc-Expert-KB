# 研发项目结案核证案例

<a id="r01"></a>

## R01 两类汇报如何共用项目轮次和终态

用户纠正了从某份竞品报告反推研发轮次的做法。项目的全部 Word、Excel、PPT 和 PDF 在开始时已统一抽取，实际发生的轮次、成败属于这份资料包，竞品汇报和现场评审都应引用同一结果。用户以“两轮后失败”举例说明，并要求使用旧抽取时展示生成日期和距今天数。助手接受了这一区分。示例里的两轮和失败是用户设想的情形。

<a id="r02"></a>

## R02 用户要先审数据，模板却默认只有一页

用户在一次审稿中追问该列两类检测结果的页为何只剩一页。助手定位到页清单缺失，仍需重读部分源报告。独立的另一次委托明确要求先看提取结果，助手交出了按报告分组的结构化数据及校核摘要。这个阶段能够审核报告是否齐全、分类和结论是否有原件支撑。

<a id="r03"></a>

## R03 原始报告独立出稿后如何核 Word 与 PPT

用户要求独立完成一个结案项目，排除同项目旧资料。助手报告从计划书与九份原始 PDF 取数，在两份成品的主表逐列覆盖七份物性或理化报告，另两份试穿材料归入附录，并汇报了附件页数复核。另一项目的交付记录则明示一份功能报告受模板限制未纳入，即便结构检查通过仍有缺项。两个例子的报告数分别取自各自资料包。
